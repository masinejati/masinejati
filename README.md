**1. Face Mask Detection Using Deep Learning**

Used a pretrained MobileNetV2 model with ImageNet weights.
Worked with a dataset of approximately 4,000 images.
Applied image preprocessing, data augmentation, and transfer learning.
Achieved approximately 98% validation accuracy during model evaluation.
Tested the trained model on additional photographs collected independently.

Technologies: Python, TensorFlow, Keras, MobileNetV2, OpenCV
